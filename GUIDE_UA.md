# Як користуватися Excel-проєктом і презентувати його на співбесіді

## Що змінилося порівняно з навчальною роботою

- Створено нову презентаційну версію, оригінальний файл збережений окремо.
- Прибрано прив'язку стажу до `TODAY()`; дата звіту вказана на Dashboard (01.01.2023).
- Створено інтерактивний дашборд із двома випадаючими фільтрами (відділ і стать) та чотирма графіками.
- Показники розраховуються формулами; їхні джерела можна перевірити на аркуші Analysis.
- Додано перевірки якості на Data_Quality та визначення метрик на Methodology.
- Для GitHub підготовлено англомовний README зі скриншотом.

## Як працювати

1. Відкрити Excel_HR_Workforce_Portfolio.xlsx у Microsoft Excel.
2. На Dashboard змінювати Department (C5), Gender (I5) і As of date (M5).
3. Значення KPI та графіки мають автоматично змінюватися.
4. Перевірити формули на Analysis, статус і стаж на Employee_Data.
5. Повернути стандартну дату 01.01.2023 і фільтри All departments / All перед показом роботодавцю.

## Чесне позиціонування

Це удосконалена **портфоліо-версія** вашого курсового Excel-проєкту: складніші елементи інтерфейсу та логіки додані вже після завершення курсу. На співбесіді не потрібно стверджувати, що весь поточний дашборд у такому вигляді ви самостійно зробили в березні. Натомість можете пояснити, як розумієте формули й методику тепер.

Вихідний `.xlsx` є навчальним, зі штучними особовими даними, а не базою реальних працівників.
